# Fonts

Latin-subset woff2 files used by the site. Pages load these from `/fonts/` only; no third-party font host is used.

| File | Family | Weights | Notes |
| --- | --- | --- | --- |
| `archivo-latin.woff2` | Archivo | 600, 700, 800 | Variable font; only those weights are declared. |
| `ibm-plex-sans-latin.woff2` | IBM Plex Sans | 400, 500, 600, 700 | Variable font; only those weights are declared. |
| `ibm-plex-mono-latin-400.woff2` | IBM Plex Mono | 400 | Static. |
| `ibm-plex-mono-latin-500.woff2` | IBM Plex Mono | 500 | Static. |

Files are the official latin subsets for those families and weights (variable files where the foundry ships one file for several weights). All three families are licensed under the SIL Open Font License 1.1; see `OFL-Archivo.txt` and `OFL-IBMPlex.txt`.
