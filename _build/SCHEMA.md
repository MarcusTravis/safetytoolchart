# Safety Tool Chart — data schema and rules

Site: "Safety Tool Chart". Pages project / default URL: https://safetytoolchart.pages.dev (constant CANON in _build/generate.py).
Repo: MarcusTravis/safetytoolchart. Plain static HTML/CSS/JS generated by `python3 _build/generate.py`; generated HTML is committed. Cloudflare Pages: no build command, output = repo root.

## Data files (one JSON array per category, in _build/)
- harnesses.json   — full-body harnesses (construction, general industry, tower/climbing, arc-flash, positioning)
- lanyards.json    — shock-absorbing lanyards (single/twin leg, 6 ft / 12 ft free fall), positioning lanyards, restraint lanyards
- srls.json        — self-retracting lifelines: personal (web/cable, single/twin), Class 1 / Class 2, leading-edge (SRL-LE), SRL-R (rescue), Z359.14 types
- anchors.json     — anchorage connectors: beam clamps/trolleys, cross-arm straps/tie-off adaptors, roof anchors, D-bolts / concrete anchors, weld-on / bolt-on anchors
- connectors.json  — snap hooks, rebar hooks, carabiners
- lifelines.json   — horizontal lifeline kits (temporary/portable), rope grabs / vertical lifelines
- rescue.json      — rescue and descent devices, rescue/retrieval systems, suspension trauma straps

## Price rule (one rule for every page; stated in each table caption)
"Price = lowest in-stock price for a new unit of that exact part number seen on a public US retailer or manufacturer-store listing (seller named and linked), checked on the date shown. No affiliate links. If no live price was found, a $ band is shown as an editorial estimate."
Bands: $ under $100 · $$ $100–$250 · $$$ $250–$600 · $$$$ $600–$1,500 · $$$$$ over $1,500
Never write a number you did not read on a live page this session. Strip any affiliate/tracking parameters from URLs.

## Hard rules
- Facts only from official manufacturer pages / spec sheets / instruction manuals, and public retailer listings for that exact part number. Record the source URL (spec_url) on every row. Specs seen only in a search-result snippet are NOT good enough — open the page; if you can't, drop the row.
- Never copy marketing text, photos, or tables verbatim; write short notes in original words.
- Never invent numbers; leave null rather than guess. A missing number is fine.
- No ads, no affiliate links.
- Nothing about the site owner's location, employer, or personal life.
