Harnesses

Full-body harnesses for construction, general industry, tower climbing, positioning and confined-space work. One row per commonly sold part number, with class, D-rings, capacity, sizes and a link to the maker’s own spec page.

Safety note. Reference only — not training and not a substitute for the manufacturer’s instructions, a competent person, or OSHA/ANSI requirements. Inspect gear before each use, remove from service any equipment that has arrested a fall, and verify specs with the manufacturer.

A full-body harness is the part of a fall arrest system that holds the worker, usually attached at a dorsal D-ring. Under ANSI/ASSP Z359.11 harnesses carry class letters by attachment point (A fall arrest, D suspension, E confined space, L ladder climbing, P work positioning), and the maker rates each one for a user weight range that includes clothing and tools. OSHA’s 1926.502(d)(16) test criteria assume a combined weight under 310 lb, so heavier users need to check the capacity column and the label. See the class breakdown on Basics for more.
